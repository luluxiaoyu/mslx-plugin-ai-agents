# 文件操作与人工确认

先确定节点、实例 ID 和实例目录。文件路径使用实例内的相对路径；删除前优先检查目标位置，并在需要时创建备份。

覆盖已有文件、删除文件或目录、删除实例、删除模组或插件、还原或删除备份时，工具会创建待确认操作。管理员应检查节点、实例、路径和操作影响后再决定。

外部 Agent 收到操作编号后，引导管理员打开当前节点的 AI 助手 → MCP → 待确认操作。这里可以直接确认或拒绝，无需配置模型 API Key。使用 `query_operation_status` 跟进结果，确认通过后系统自动执行，无需重新提交。操作编号只能用原来提交操作的令牌查询。

禁止把外部 Agent 的文字确认、请求参数或模型判断当作面板审批。需要审批的操作挂起时，应向用户报告正在等待确认。
